Novarum is a decentralized social platform. Each community connects to an Anchor homeserver that manages its data and federation.

## Get started

To run your own homeserver, follow the [deployment guide](/guides/deployment/).

## Bots

Build bots with commands, embeds and buttons using [`@novarum/sdk`](/bots/getting-started/).

## API

There's a Scalar OpenAPI specification for the Novarum API. You can find it on the `/openapi` route of any homeserver.
